# 1. 概要 (v2)
本ドキュメントは、「簡易メモアプリ」バージョン2の外部設計を定義するものである。

# 2. 画面設計
- **変更なし。**
- v1で定義されたメインウィンドウ、詳細ウィンドウのUIレイアウト、ウィジェットの種類、配置に変更はない。

### 2.1. メインウィンドウ
- ウィンドウタイトル: 「簡易メモアプリ」
- 左フレーム: タイトル入力欄、本文入力エリア、保存ボタン
- 右フレーム: メモ一覧リストボックス

### 2.2. 詳細ウィンドウ
- ウィンドウタイトル: 「メモ詳細」
- 本文を編集可能なテキストエリア
- 「更新」「削除」ボタン

# 3. 画面遷移
- **変更なし。**
- v1で定義された画面遷移フロー（起動→保存→選択→更新・削除）に変更はない。ユーザー体験はv1と同一である。
