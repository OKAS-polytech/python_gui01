# 1. 概要 (v2)
本ドキュメントは、「簡易メモアプリ」のバージョン2における要件を定義するものである。v1の機能に加え、データ永続化とソフトウェアアーキテクチャの改善を目的とする。

# 2. アプリケーションの目的
ユーザーが日常的なメモを簡単に作成、保存、閲覧、編集、削除できるGUIアプリケーションを提供する。アプリケーションを終了してもメモデータは失われない。

# 3. 機能要件

### 3.1. メモ作成機能
- (変更なし) ユーザーはメモのタイトルと本文を入力できる。

### 3.2. メモ保存機能
- 「保存」ボタンをクリックすると、入力されたタイトルと本文が**テキストファイルとして永続的に保存される**。
- 保存時には、保存した日時も記録される。
- 保存が完了すると、メモ一覧に表示される。
- **各メモは、ユニークなID（例: 作成時のタイムスタンプ）をファイル名とする個別の`.txt`ファイルとして保存される。**

### 3.3. メモ一覧表示機能
- **アプリケーション起動時に、保存されているすべてのメモファイルを読み込み、一覧に表示する。**

### 3.4. メモ詳細表示機能
- (変更なし) メモ一覧から特定のメモをクリックすると、詳細ウィンドウが表示される。

### 3.5. メモ編集機能
- (変更なし) 詳細ウィンドウで本文を編集し、「更新」ボタンで変更を保存できる。**変更は該当のテキストファイルに上書き保存される。**

### 3.6. メモ削除機能
- (変更なし) 詳細ウィンドウで「削除」ボタンをクリックすると、表示しているメモを削除できる。**削除時には、該当のテキストファイルも物理的に削除される。**

# 4. 非機能要件

### 4.1. 使用技術
- プログラミング言語: Python 3
- GUIライブラリ: Tkinter

### 4.2. 実行環境
- Python 3が動作する一般的なデスクトップ環境。

### 4.3. データ永続化
- **メモデータは、`data/`ディレクトリ内にテキストファイル (`.txt`) として保存する。**
- ファイル名はメモのユニークID（例: `1672532400.txt`）とする。
- ファイルの中身は、1行目にタイトル、2行目にタイムスタンプ、3行目以降に本文を記録する形式とする。

### 4.4. ソフトウェアアーキテクチャ
- **MVC (Model-View-Controller) アーキテクチャを採用する。**
    - **Model**: データ（`Memo`クラス）と、その永続化ロジック（ファイルI/O）を担当する。
    - **View**: UIの表示とレイアウトのみを担当する。
    - **Controller**: ユーザーからの入力を受け取り、ModelとViewを操作する。
- **`Memo`クラスは、データ構造のみを保持する独立したクラスとして定義する。**
