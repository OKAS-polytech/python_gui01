# 1. 概要 (v2)
本ドキュメントは、「簡易メモアプリ」バージョン2の内部設計を定義するものである。MVCアーキテクチャの採用とデータ永続化の実装に伴い、プログラム構造を全面的に刷新する。

# 2. アーキテクチャ
- **MVC (Model-View-Controller) アーキテクチャを採用する。**
- 各コンポーネントは独立したPythonファイルとして実装する。
    - `src/memo.py`: `Memo`データクラス（データの構造）
    - `src/model.py`: `MemoModel`クラス（データ永続化ロジック）
    - `src/view.py`: `View`クラス（UIの表示）
    - `src/controller.py`: `Controller`クラス（ビジネスロジック）
    - `src/main.py`: アプリケーションの起動、MVCの初期化

# 3. クラス設計

### 3.1. `Memo` クラス (`src/memo.py`)
- **責務**: 一つのメモに関するデータを保持する。ロジックは持たない。
- **プロパティ**:
    - `id`: `str` (ユニークID、ファイル名にも使用)
    - `title`: `str`
    - `content`: `str`
    - `timestamp`: `str`

### 3.2. `MemoModel` クラス (`src/model.py`)
- **責務**: メモデータの永続化処理（ファイルの読み書き）を担当する。
- **プロパティ**:
    - `data_dir`: `str` (データ保存ディレクトリ、例: "data/")
- **メソッド**:
    - `get_all_memos()`: `data_dir`内の全`.txt`ファイルを読み込み、`Memo`オブジェクトのリストを返す。
    - `save_memo(memo: Memo)`: `Memo`オブジェクトを受け取り、`data_dir`にテキストファイルとして保存する。ファイル名は`memo.id + ".txt"`。
    - `delete_memo(memo_id: str)`: 指定されたIDのメモファイルを削除する。

### 3.3. `View` クラス (`src/view.py`)
- **責務**: GUIの構築、表示、更新のみを担当する。アプリケーションロジックは含まない。
- **プロパティ**:
    - `window`: メインウィンドウ (`tk.Tk`)
    - `title_entry`, `content_text`, `memo_listbox` などのUIウィジェット。
- **メソッド**:
    - `__init__(window)`: ウィンドウを受け取り、UIウィジェットを作成・配置する。
    - `bind_save_button(handler)`, `bind_memo_selection(handler)` など: Controllerから渡されたイベントハンドラをウィジェットにバインドする。
    - `update_memo_list(memos)`: `Memo`オブジェクトのリストを受け取り、リストボックスの表示を更新する。
    - `get_title()`, `get_content()`: 入力欄の現在の値を取得する。
    - `clear_input_fields()`: 入力欄をクリアする。
    - `show_detail_window(memo, update_handler, delete_handler)`: 詳細ウィンドウを表示する。更新・削除ボタンのハンドラはControllerから受け取る。

### 3.4. `Controller` クラス (`src/controller.py`)
- **責務**: ユーザーからの入力を受け取り、ModelとViewを操作してアプリケーションのロジックを実行する。
- **プロパティ**:
    - `model`: `MemoModel`のインスタンス。
    - `view`: `View`のインスタンス。
- **メソッド**:
    - `__init__(model, view)`: ModelとViewのインスタンスを受け取り、イベントハンドラをViewにバインドする。
    - `_handle_save()`: Viewからタイトルと本文を取得し、新しい`Memo`オブジェクトを作成してModelに保存を依頼し、Viewのリストを更新する。
    - `_handle_memo_select()`: Viewで選択されたメモの情報を基に、Modelから完全な`Memo`オブジェクトを取得し、Viewに詳細ウィンドウの表示を依頼する。
    - `_handle_update(memo_id, new_content)`: Modelにメモの更新を依頼し、Viewのリストを更新する。
    - `_handle_delete(memo_id)`: Modelにメモの削除を依頼し、Viewのリストを更新する。

# 4. データフロー

### 4.1. 起動時
1.  `main.py`が`MemoModel`, `View`, `Controller`をインスタンス化する。
2.  `Controller`が`MemoModel`に全メモの取得を依頼する (`get_all_memos`)。
3.  `Controller`が取得したメモのリストを`View`に渡し、一覧の表示を依頼する (`update_memo_list`)。

### 4.2. メモ保存時
1.  ユーザーがViewの「保存」ボタンをクリック。
2.  Viewにバインドされた`Controller._handle_save`が呼び出される。
3.  ControllerがViewから入力値を取得する。
4.  Controllerが`Memo`オブジェクトを作成し、`MemoModel.save_memo`を呼び出す。
5.  Modelがファイルに書き込む。
6.  ControllerがModelから最新のメモリストを再取得し、Viewの`update_memo_list`を呼び出して画面を更新する。
