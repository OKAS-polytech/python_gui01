# 1. 概要 (v2)
本ドキュメントは、内部設計書(v2)および設計手順書(v2)に基づき、「簡易メモアプリ」バージョン2の具体的な開発・実装手順を定義するものである。

        ├── view.py       (新規)

# 3. 実装フェーズ

### ステップ 3.1: プロジェクト構造のセットアップ
1.  `data` ディレクトリと `docs2` ディレクトリを作成する。
2.  `src` ディレクトリ内に、`memo.py`, `model.py`, `view.py`, `controller.py` の4つの空ファイルを作成する。

### ステップ 3.2: `Memo` データクラスの実装 (`src/memo.py`)
1.  `dataclasses` モジュールをインポートする (`from dataclasses import dataclass`)。
2.  `@dataclass` デコレータを使い、`Memo` クラスを定義する。
3.  クラス内に、`id: str`, `title: str`, `content: str`, `timestamp: str` の4つの型ヒント付きプロパティを定義する。

### ステップ 3.3: `MemoModel` クラスの実装 (`src/model.py`)
1.  `os` と `glob` モジュール、および `src.memo` から `Memo` クラスをインポートする。
2.  `MemoModel` クラスを定義する。
3.  `__init__` でデータディレクトリのパス (`self.data_dir`) を設定し、`os.makedirs` でディレクトリが存在しない場合に作成する処理を追加する。
4.  `get_all_memos` メソッドを実装する。`glob.glob` で `data/*.txt` を検索し、各ファイルを読み込んで`Memo`オブジェクトを生成し、リストとして返す。
5.  `save_memo` メソッドを実装する。受け取った`Memo`オブジェクトの情報を、指定されたフォーマットでテキストファイルに書き込む。ファイル名は `f"{memo.id}.txt"` とする。
6.  `delete_memo` メソッドを実装する。指定されたIDに対応するファイルを `os.remove` で削除する。

### ステップ 3.4: `View` クラスの実装 (`src/view.py`)
1.  `tkinter` をインポートする。
2.  `View` クラスを定義する。
3.  `__init__` で `tk.Tk` インスタンスを受け取り、v1の`create_widgets`に相当する処理をここに記述してUIを構築する。UIウィジェットは `self.title_entry` のようにインスタンス変数として保持する。
4.  `bind_save_button(self, handler)` のようなメソッド群を定義する。これらは引数で受け取った `handler` (コールバック関数) を、対応するウィジェットの `command` や `bind` メソッドに設定する。
5.  `update_memo_list(self, memos)` を実装する。`memos` (Memoオブジェクトのリスト) を受け取り、リストボックスを更新する。
6.  その他、UIの状態を取得・変更するためのヘルパーメソッド（`get_title`, `clear_input_fields`など）を実装する。

### ステップ 3.5: `Controller` クラスの実装 (`src/controller.py`)
1.  `datetime`, `src.memo.Memo` などをインポートする。
2.  `Controller` クラスを定義する。
3.  `__init__` で `model` と `view` のインスタンスを受け取り、プロパティとして保持する。
4.  `__init__` 内で、`self.view.bind_save_button(self._handle_save)` のように、Viewのバインドメソッドを呼び出して、自身の処理メソッドをイベントハンドラとして登録する。
5.  `_handle_save` などのイベントハンドラメソッドをプライベートメソッドとして実装する。これらのメソッドは、Viewから情報を取得し、Modelを操作し、最後にViewを更新するという、内部設計書通りのロジックを実行する。
6.  アプリ起動時に初期データをロードするための `load_initial_data` のようなメソッドを実装する。

### ステップ 3.6: `main.py` の修正
1.  既存の `MemoApp` クラスと関連ロジックをすべて削除する。
2.  `tkinter`, `src.model`, `src.view`, `src.controller` をインポートする。
3.  `if __name__ == "__main__":` ブロック内で、以下の処理を行う:
    1.  `model = MemoModel()` をインスタンス化。
    2.  `root = tk.Tk()` でウィンドウを作成。
    3.  `view = View(root)` をインスタンス化。
    4.  `controller = Controller(model, view)` をインスタンス化。
    5.  `root.mainloop()` を呼び出す。
