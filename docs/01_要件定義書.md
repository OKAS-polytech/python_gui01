# 1. 概要
本ドキュメントは、PythonのTkinterを使用して開発する「簡易メモアプリ」の要件を定義するものである。

# 2. アプリケーションの目的
ユーザーが日常的なメモを簡単に作成、保存、閲覧、編集、削除できるGUIアプリケーションを提供する。

# 3. 機能要件

### 3.1. メモ作成機能
- ユーザーはメモのタイトルを1行で入力できる。
- ユーザーはメモの本文を複数行で入力できる。

### 3.2. メモ保存機能
- 「保存」ボタンをクリックすると、入力されたタイトルと本文が保存される。
- 保存時には、保存した日時も記録される。
- 保存が完了すると、メモ一覧に「タイトル - 保存日時」の形式で表示される。

### 3.3. メモ一覧表示機能
- 保存されたメモが、メイン画面の一覧エリアにリスト形式で表示される。

### 3.4. メモ詳細表示機能
- メモ一覧から特定のメモをクリックすると、そのメモの本文が閲覧できる詳細ウィンドウが表示される。

### 3.5. メモ編集機能
- 詳細ウィンドウ内で本文を編集し、「更新」ボタンで変更を保存できる。

### 3.6. メモ削除機能
- 詳細ウィンドウ内で「削除」ボタンをクリックすると、表示しているメモを削除できる。
- 削除後、詳細ウィンドウは閉じられ、メイン画面のメモ一覧からも該当のメモが削除される。

# 4. 非機能要件

### 4.1. 使用技術
- プログラミング言語: Python 3
- GUIライブラリ: Tkinter

### 4.2. 実行環境
- Python 3が動作する一般的なデスクトップ環境（Windows, macOS, Linux）

### 4.3. データ永続化
- 本バージョンでは、データはアプリケーション実行中のメモリ上でのみ保持する。永続化は将来の課題とする。
