# 1. 概要
本ドキュメントは、「簡易メモアプリ」の内部設計を定義するものである。プログラムのアーキテクチャ、クラス構造、主要な関数、データ構造について記述する。

# 2. プログラム構造
- アプリケーションは単一のPythonファイル (`src/main.py`) で構成される。
- `MemoApp` という単一のクラスが、アプリケーションのメインロジックとGUIコンポーネントの管理を行う。
- イベント駆動モデルを採用し、ユーザーのアクション（ボタンクリック、リスト選択など）に応じて特定のメソッド（イベントハンドラ）が呼び出される。

# 3. データ構造
- メモデータは、アプリケーションの実行中、メモリ上のリストで管理する。
- リストの各要素は、1つのメモを表す辞書オブジェクトとする。
- メモ辞書の構造:
    ```python
    {
        "id": int,          # ユニークなID
        "title": str,       # メモのタイトル
        "content": str,     # メモの本文
        "timestamp": str    # 保存・更新日時 (ISO 8601形式の文字列)
    }
    ```
- メモのIDは、メモ作成時にユニークな値（例: タイムスタンプ）を割り当てることで一意性を担保する。

# 4. クラス設計 (`MemoApp`)

### 4.1. プロパティ
- `self.window`: Tkinterのメインウィンドウ (`tk.Tk`)。
- `self.memos`: メモ辞書のリスト。アプリケーションの状態を保持する。
- `self.title_entry`: タイトル入力用の `tk.Entry` ウィジェット。
- `self.content_text`: 本文入力用の `tk.Text` ウィジェット。
- `self.memo_listbox`: メモ一覧表示用の `tk.Listbox` ウィジェット。

### 4.2. メソッド

#### `__init__(self, window)`
- コンストラクタ。
- メインウィンドウの初期設定（タイトル、サイズなど）を行う。
- `self.memos` を空のリストとして初期化する。
- `self.create_widgets()` を呼び出してUIを構築する。

#### `create_widgets(self)`
- UIウィジェット（ラベル、入力欄、ボタン、リストボックス）をすべて作成し、画面に配置する。
- イベントハンドラを各ウィジェットにバインドする。
    - 保存ボタンの `command` に `self.save_memo` を設定。
    - リストボックスの `<<ListboxSelect>>` イベントに `self.on_memo_select` をバインド。

#### `save_memo(self)`
- 「保存」ボタンのイベントハンドラ。
- `self.title_entry` と `self.content_text` から現在の入力値を取得する。
- タイトルが空の場合は処理を中断する。
- 新しいメモ辞書を作成し、`self.memos` リストに追加する。
- `self.update_memo_list()` を呼び出して一覧を更新する。
- 入力欄をクリアする。

#### `update_memo_list(self)`
- `self.memos` リストの内容に基づいて、`self.memo_listbox` の表示を更新する。
- まずリストボックスの内容をすべてクリアし、その後 `self.memos` の各メモを「タイトル - 日時」の形式で追加する。

#### `on_memo_select(self, event)`
- `self.memo_listbox` で項目が選択されたときのイベントハンドラ。
- 選択されたインデックスを取得し、対応するメモデータを `self.memos` から検索する。
- `self.show_detail_window(memo)` を呼び出して詳細ウィンドウを開く。

#### `show_detail_window(self, memo)`
- 詳細表示用の新しい `tk.Toplevel` ウィンドウを生成する。
- 本文表示用の `tk.Text` ウィジェットと、「更新」「削除」ボタンを配置する。
- `tk.Text` に選択されたメモの本文を表示する。
- 「更新」ボタンの `command` に、選択されたメモを更新するラムダ式または内部関数を設定 (`update_memo`)。
- 「削除」ボタンの `command` に、選択されたメモを削除するラムダ式または内部関数を設定 (`delete_memo`)。

#### `update_memo(self, memo_id, new_content, detail_window)`
- 詳細ウィンドウの「更新」ボタンから呼び出される。
- `memo_id` をもとに `self.memos` 内の該当メモを検索し、本文 (`content`) とタイムスタンプを更新する。
- `detail_window` を閉じる。
- `self.update_memo_list()` を呼び出してメインウィンドウの一覧を更新する。

#### `delete_memo(self, memo_id, detail_window)`
- 詳細ウィンドウの「削除」ボタンから呼び出される。
- `memo_id` をもとに `self.memos` 内の該当メモをリストから削除する。
- `detail_window` を閉じる。
- `self.update_memo_list()` を呼び出してメインウィンドウの一覧を更新する。

# 5. 起動処理
- `if __name__ == "__main__":` ブロック内で行う。
- `tk.Tk()` でルートウィンドウを作成。
- `MemoApp(root_window)` でアプリケーションインスタンスを生成。
- `root_window.mainloop()` でイベントループを開始する。
