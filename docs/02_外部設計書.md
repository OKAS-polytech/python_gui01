# 1. 概要
本ドキュメントは、「簡易メモアプリ」の外部設計を定義するものである。主にUIデザインと画面遷移について記述する。

# 2. 画面設計

### 2.1. メインウィンドウ
- **ウィンドウタイトル**: 「簡易メモアプリ」
- **レイアウト**:
    - ウィンドウは左右2つのメインフレームに分割する。
    - **左フレーム（入力エリア）**:
        - 「タイトル」ラベルと、その下に1行テキスト入力欄（`Entry`ウィジェット）。
        - 「本文」ラベルと、その下に複数行テキスト入力エリア（`Text`ウィジェット）。
        - 最下部に「保存」ボタン（`Button`ウィジェット）。
    - **右フレーム（一覧エリア）**:
        - 「メモ一覧」ラベル。
        - その下に保存済みメモを表示するリストボックス（`Listbox`ウィジェット）。

![メインウィンドウレイアウト](https://i.imgur.com/8a1Z4g3.png)

### 2.2. 詳細ウィンドウ
- **ウィンドウタイトル**: 「メモ詳細」
- **レイアウト**:
    - 選択されたメモの本文を表示するための、編集可能な複数行テキストエリア（`Text`ウィジェット）。
    - 最下部に「更新」ボタンと「削除」ボタンを配置。

# 3. 画面遷移

1.  **起動時**:
    - メインウィンドウが表示される。メモ一覧は空の状態。
2.  **メモ保存**:
    - ユーザーがタイトルと本文を入力し、「保存」ボタンをクリックする。
    - 入力内容が保存され、右側のメモ一覧に「タイトル - 保存日時」が追加される。画面遷移は発生しない。
3.  **メモ選択**:
    - ユーザーがメモ一覧から特定の項目をシングルクリックで選択する。
    - 選択されたメモの内容が表示された、新しい「詳細ウィンドウ」がモーダルウィンドウとして表示される。
4.  **メモ更新**:
    - ユーザーが詳細ウィンドウで本文を編集し、「更新」ボタンをクリックする。
    - 変更が保存され、詳細ウィンドウが自動的に閉じる。
5.  **メモ削除**:
    - ユーザーが詳細ウィンドウで「削除」ボタンをクリックする。
    - 確認ダイアログなしでメモが削除され、詳細ウィンドウが自動的に閉じる。メインウィンドウのメモ一覧からも該当項目が削除される。

# 4. コンポーネント詳細

- **タイトル入力欄**: `tkinter.Entry`
- **本文入力エリア**: `tkinter.Text`
- **保存ボタン**: `tkinter.Button` (イベント: `save_memo`)
- **メモ一覧**: `tkinter.Listbox` (イベント: `<<ListboxSelect>>`)
- **詳細ウィンドウ本文エリア**: `tkinter.Text`
- **更新ボタン**: `tkinter.Button` (イベント: `update_memo`)
- **削除ボタン**: `tkinter.Button` (イベント: `delete_memo`)
