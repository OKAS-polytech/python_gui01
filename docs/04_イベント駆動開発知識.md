# 1. 概要
本ドキュメントは、「簡易メモアプリ」の開発で採用するイベント駆動開発（Event-Driven Development）に関する基本的な知識をまとめたものである。

# 2. イベント駆動開発とは
イベント駆動開発は、プログラムのフローがユーザーのアクションやシステムのメッセージといった「イベント」によって決定されるプログラミングパラダイムである。GUIアプリケーション、Webサーバー、組み込みシステムなど、非同期的な入力を扱うシステムで広く採用されている。

### 2.1. 主要な構成要素
- **イベント (Event)**:
    - ユーザーのアクション（マウスクリック、キー入力など）や、システムの通知（タイマー、データ受信など）によって発生する事象。
- **イベントループ (Event Loop)**:
    - アプリケーションの心臓部。イベントの発生を常に監視し、イベントが発生すると、それに対応する処理（イベントハンドラ）を呼び出す無限ループ。
- **イベントハンドラ (Event Handler)** / コールバック関数 (Callback Function):
    - 特定のイベントが発生したときに実行されるように、あらかじめ登録された関数やメソッド。イベントに対する具体的な処理内容を記述する。

### 2.2. 動作フロー
1.  アプリケーションが起動し、UIコンポーネントの初期化とイベントハンドラの登録を行う。
2.  イベントループが開始され、イベントの待機状態に入る。
3.  ユーザーがボタンをクリックする（イベント発生）。
4.  イベントループがイベントを検知する。
5.  イベントループは、そのボタンに登録（バインド）されているイベントハンドラを呼び出す。
6.  イベントハンドラの処理（例: メモの保存）が実行される。
7.  イベントハンドラの処理が終了すると、制御はイベントループに戻り、再び次のイベントを待機する。

# 3. Tkinterにおけるイベント駆動
Tkinterは、イベント駆動モデルに完全に基づいたGUIツールキットである。

### 3.1. イベントループの開始
- `window.mainloop()` を呼び出すことで、Tkinterのイベントループが開始される。
- これ以降、プログラムはイベントの発生を待ち受け、ユーザーの操作に応答するようになる。`mainloop()` が終了すると、アプリケーションも終了する。

### 3.2. イベントハンドラの登録（バインディング）
Tkinterでは、イベントとイベントハンドラを結びつける（バインドする）方法が主に2つある。

#### 1. `command` オプション
- `Button` や `Checkbutton` などの一部のウィジェットは、クリックされたときに実行する関数を `command` オプションで直接指定できる。これは最もシンプルな方法である。
    ```python
    def on_save_click():
        print("保存ボタンがクリックされました")

    save_button = tk.Button(window, text="保存", command=on_save_click)
    ```

#### 2. `bind()` メソッド
- より汎用的な方法で、あらゆるウィジェットの、あらゆる種類のイベント（マウスクリック、キー入力、フォーカス移動など）に対して関数をバインドできる。
- イベントの種類は文字列（例: `<Button-1>` はマウス左クリック）で指定する。
    ```python
    def on_listbox_select(event):
        # eventオブジェクトにはイベントに関する情報が含まれる
        print("リストボックスの項目が選択されました")

    listbox = tk.Listbox(window)
    listbox.bind("<<ListboxSelect>>", on_listbox_select)
    ```
    - `<<ListboxSelect>>` は、リストボックスの選択が変更されたことを示す「仮想イベント」。

# 4. イベント駆動開発のメリット
- **応答性**: ユーザーのアクションに即座に反応できるため、インタラクティブなアプリケーションに適している。
- **柔軟性**: イベントハンドラを追加・変更することで、機能の拡張や修正が容易になる。
- **シンプルな構造**: プログラムの各部分は、特定のイベントに対応する自己完結したロジックとなり、コードの見通しが良くなる。
