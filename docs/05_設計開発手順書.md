# 1. 概要
本ドキュメントは、要件定義書、外部設計書、内部設計書に基づき、「簡易メモアプリ」の具体的な開発手順を定義するものである。

# 2. 開発環境の準備
- **言語**: Python 3
- **ライブラリ**: Tkinter (Python標準ライブラリ)
- **ディレクトリ構造**:
    ```
    /
    ├── docs/
    │   ├── 01_要件定義書.md
    │   ├── ...
    └── src/
        └── main.py
    ```

# 3. 実装フェーズ

### ステップ 3.1: プロジェクト構造のセットアップ
1.  `docs` ディレクトリと `src` ディレクトリを作成する。
2.  `src` ディレクトリ内に `main.py` ファイルを作成する。

### ステップ 3.2: アプリケーションの基本骨格の実装
1.  `main.py` に `tkinter` をインポートする。
2.  `MemoApp` クラスを定義する。
3.  `__init__` メソッドでメインウィンドウ (`tk.Tk`) を受け取り、ウィンドウタイトルや初期サイズを設定する。
4.  `if __name__ == "__main__":` ブロックで、`tk.Tk()` インスタンスを生成し、`MemoApp` クラスをインスタンス化し、`mainloop()` を呼び出すことで、アプリケーションの基本的な起動シーケンスを実装する。

### ステップ 3.3: UIウィジェットの作成と配置
1.  `MemoApp` クラス内に `create_widgets` メソッドを定義し、`__init__` から呼び出す。
2.  外部設計書に従い、`tk.Label`, `tk.Entry`, `tk.Text`, `tk.Button`, `tk.Listbox` などのウィジェットをインスタンス化する。
3.  `pack()` や `grid()` ジオメトリマネージャを使い、ウィジェットをメインウィンドウ上に配置する。

### ステップ 3.4: メモ保存機能の実装
1.  `MemoApp` クラスの `__init__` で、メモを保存するための空のリスト `self.memos = []` を初期化する。
2.  `save_memo` メソッドを実装する。このメソッドは、`Entry` と `Text` ウィジェットから値を取得し、内部設計書で定義した辞書形式でメモデータを作成し、`self.memos` リストに追加する。
3.  `update_memo_list` メソッドを実装する。このメソッドは `Listbox` をクリアし、`self.memos` の内容をループ処理してリストを再描画する。
4.  `save_memo` メソッドの最後に `update_memo_list()` の呼び出しを追加する。
5.  `create_widgets` メソッド内で、「保存」ボタンの `command` オプションに `self.save_memo` を設定する。

### ステップ 3.5: メモ詳細表示機能の実装
1.  `on_memo_select` メソッドを実装する。このメソッドは `event` を引数に取り、`Listbox` で選択されている項目を取得する。
2.  `create_widgets` メソッド内で、`Listbox` ウィジェットに対し、`bind("<<ListboxSelect>>", self.on_memo_select)` を呼び出し、イベントとハンドラを紐付ける。
3.  `show_detail_window` メソッドを実装する。このメソッドは選択されたメモオブジェクトを引数に取り、`tk.Toplevel` を使って新しいウィンドウを生成する。
4.  詳細ウィンドウ内に `tk.Text` と2つの `tk.Button`（「更新」「削除」）を配置し、メモの本文を表示する。

### ステップ 3.6: メモ更新・削除機能の実装
1.  `update_memo` メソッドを実装する。このメソッドは、メモのID、新しい本文、詳細ウィンドウのインスタンスを引数に取り、`self.memos` 内のデータを更新後、詳細ウィンドウを閉じて `update_memo_list` を呼び出す。
2.  `delete_memo` メソッドを実装する。このメソッドは、メモのIDと詳細ウィンドウのインスタンスを引数に取り、`self.memos` からデータを削除後、詳細ウィンドウを閉じて `update_memo_list` を呼び出す。
3.  `show_detail_window` メソッド内で、「更新」「削除」ボタンの `command` に、ラムダ式などを用いて `update_memo` および `delete_memo` メソッドを適切な引数で呼び出すように設定する。

# 4. テストフェーズ
1.  `python src/main.py` コマンドでアプリケーションを起動する。
2.  以下の項目について、手動で動作確認を行う。
    - メモを新規作成し、保存できるか。
    - 保存したメモが一覧に正しく表示されるか。
    - 一覧からメモを選択し、詳細ウィンドウが正しく表示されるか。
    - 詳細ウィンドウでメモを編集し、「更新」できるか。
    - 更新後、一覧表示も（日時の部分が）更新されるか。
    - 詳細ウィンドウでメモを「削除」できるか。
    - 削除後、一覧から正しく消去されるか。
